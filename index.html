PROJECT OVERVIEW

Making loan risk analysis more data-driven.

The project investigates how machine-learning models can classify loan applications into potential default and non-default categories. It compares two tree-based ensemble approaches on a common dataset and evaluates their results using suitable classification metrics.

✓

ObjectivePredict loan default risk from available applicant features.

✓

Research gapTraditional assessments may miss complex patterns, while imbalanced data can make defaults harder to detect.

✓

MethodPreprocess data, split into train/test sets, train both models and compare results.
