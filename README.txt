LOAN DEFAULT PREDICTION FRONTEND — WITH LOGIN AND SIGNUP

Files:
- login.html — login page
- signup.html — registration page
- index.html — main dashboard
- css/style.css — main website design
- css/auth.css — login/signup page styling
- js/auth.js — demo signup/login logic
- js/app.js — dashboard demo interaction

RUN:
1. Extract this ZIP.
2. Open the LoanDefaultFrontend folder in VS Code.
3. Install the Live Server extension.
4. Right-click login.html and choose "Open with Live Server".
5. Create an account on the signup page.
6. Sign in using the same email and password. The dashboard opens after login.
7. Use Log out on the dashboard to return to login.

IMPORTANT SECURITY NOTE:
This is frontend-only demo authentication. Accounts are stored in browser localStorage, and the demo password is not protected by a server. Use fake details and a password you do not use anywhere else. This is not production security. For real users, authentication must be handled by a backend with secure password hashing and session/token handling.

The loan prediction output is also a frontend demonstration, not a real trained Random Forest or Gradient-Boosted Trees prediction.
